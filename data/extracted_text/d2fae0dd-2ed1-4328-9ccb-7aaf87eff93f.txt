Information versus Data 
Retrieval
◼ The user of an IR system is concerned more with retrieving 
information about a subject than with retrieving data that 
satisfies a given query.
◼ A data retrieval system, such as a relational database, deals 
with data that has a well defined structure and semantics, 
while an IR system deals with natural language text which is 
not well structured.
◼ In a data retrieval system, on the contrary, a single 
erroneous object among a thousand retrieved objects 
means total failure.

Latent Semantic Analysis
◼ When we use index terms (keywords) for searching:
◼ Problem 1: Many unrelated documents may appear (because they share 
the same keyword, but not the same meaning).
◼ Problem 2: Some relevant documents may not appear (because they use 
different words to express the same concept).
◼ Instead of matching documents strictly by keywords, LSI tries to match 
them by concepts.
◼ Words that appear in similar contexts are assumed to have similar 
meanings.
◼ A document can be considered relevant even if it doesn’t contain the 
exact keyword from the query, as long as it shares the same concept.
137

◼ How LSI Works
◼ Construct a term-document matrix (M):
◼ Rows → terms (keywords)
◼ Columns → documents
◼ Each entry 𝑀𝑖,𝑗Mi,j ​ → weight showing how important term i is in 
document j.
◼ Weight often calculated using TF-IDF (term frequency–inverse document 
frequency).
◼ Apply Dimensionality Reduction (using Singular Value Decomposition, 
SVD).
◼ This reduces the large term-document matrix into a smaller concept space.
◼ Each document and query is mapped into this lower-dimensional 
space.Retrieval happens in this concept space instead of raw keyword space.
138

◼ Advantages
◼ Captures synonymy (different words, same 
meaning → car/automobile).
◼ Handles polysemy better (same word, multiple 
meanings → “bank” as riverbank or financial 
bank).
◼ Improves retrieval accuracy compared to plain 
keyword matching.
